# HR Attrition & Workforce Analysis 📊

A end-to-end HR analytics project analyzing employee attrition and
workforce trends using **Microsoft Excel** and **Tableau**.
This project uncovers key drivers of employee turnover and delivers
actionable insights through interactive dashboards and structured
reporting.

---

## 🔍 Project Overview

Employee attrition is one of the most costly challenges organizations
face. This project dives into HR data to identify patterns in employee
departures, understand workforce composition, and surface insights that
help HR teams make data-driven retention decisions.

---

## 🎯 Objectives

- Analyze overall and department-wise attrition rates
- Identify key factors contributing to employee turnover
  (age, tenure, salary, job role, satisfaction scores, etc.)
- Segment the workforce by demographics and performance
- Build interactive Tableau dashboards for HR stakeholders
- Provide Excel-based pivot reports for quick offline reference

---

## 🛠️ Tools & Technologies

| Tool        | Purpose                                      |

| Tableau     | Interactive dashboards & visual storytelling |
